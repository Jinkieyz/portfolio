Real-time shader, GLSL and Three.js

Glass optics in the browser

A cast glass form raymarched in real time, with refraction, chromatic dispersion, Fresnel and Beer-Lambert absorption written by hand in the fragment shader. A resolution scale keeps it within frame budget on modest hardware. Glass is my own material, so the optics are grounded rather than borrowed.

Live and interactive: drag to orbit, scroll to zoom, sliders for the optics.

Pipeline tool, Blender add-on in Python

Web Preflight

A pre-flight check that tells a 3D artist what a scene will actually cost in the browser, before export. It estimates triangles, draw calls (one per material, the way a WebGL renderer splits geometry) and texture memory against a target budget, and flags the glTF pitfalls that normally surface only after loading: procedural materials that will not export, non-uniform scale, missing UVs or textures. Each finding names the culprit and gives a one line fix. Spec validators and asset auditors do not estimate runtime cost; this does, where the artist works.

Procedural and generative systems

Generative pipelines in Python and Blender

The longer thread in my work is making forms by rule rather than by hand, and building the headless pipelines to run them at scale.

  • LAJFI , an evolutionary simulation built on Gielis superformulas, with a web demo and public code. github.com/Jinkieyz
  • GEMESIS / Boolean Beings , an evolutionary form system in Python and Blender; a set of the generated forms was physically cast.
  • Diffusion with Gielis positional encoding , an image model and training pipeline that encodes a procedural geometry prior.
  • Mold generator , a Blender tool that builds casting molds around a mesh.
  • Real-time 3D on the web , Three.js viewers and procedural pieces running in the browser. vetroal.se

How I work

Small, technical teams and non-standard pipelines suit me. I am comfortable scripting a tool one day and tuning a shader the next, and I care about the unglamorous parts, budgets, repeatable exports, things that do not break when someone else uses them. I am new to game engines and learning fast; the web and real-time 3D are where my hands already are.
